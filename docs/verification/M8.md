# M8 verification: bounded quiescence search

- Date: 2026-09-28
- Build profile for empirical runs: `release`

## Correctness coverage

The tactical regression position
`4k3/8/5n2/3p4/8/8/8/3QK3 w - - 0 1` previously selected `d1d5` at depth one,
scoring the pawn capture before Black's knight recapture. M8 depth one rejects that move because
the nominal leaf is stabilized by quiescence.

Focused tests additionally establish:

- forced recaptures change the leaf score before it is returned;
- quiet promotions and en-passant captures enter quiescence;
- checked nodes search quiet legal evasions and do not stand pat;
- checkmate and stalemate are recognized at the nominal horizon;
- the 32-ply safety guard searches every legal check evasion through one final finite child,
  never evaluates the checked node as stand pat, and restores the exact root;
- capture promotions exercise all four promotion kinds, including every underpromotion;
- mate found through a quiescence capture remains correctly classified by `mate_in`;
- draw claims, automatic draws, and root fallback behavior remain intact;
- principal variations remain limited to nominal-depth moves;
- total nodes include quiescence nodes exactly once and results remain deterministic.

## Independent reference check

The test `quiescence_alpha_beta_matches_unpruned_reference_and_prunes` compares a narrow-window
production search with a deliberately unpruned recursive oracle over the same tactical move set
and independently implemented cap semantics. The release-mode run returned the same exact score
inside the requested window while visiting 59 quiescence nodes instead of 137 unpruned nodes, a
56.9% reduction.

Run it with:

```sh
cargo test --release --lib \
  search::tests::quiescence_alpha_beta_matches_unpruned_reference_and_prunes \
  --locked -- --nocapture
```

## Protocol measurement

The UCI `nodes` field reports total visited nodes, including quiescence. The standard protocol has
no quiescence-node field, so the split is available through `SearchResult::quiescence_nodes`
instead of a non-standard UCI token. Release-mode process measurements produced:

| Position | Depth | Score | Total nodes | Principal variation | Best move |
| --- | ---: | ---: | ---: | --- | --- |
| Poisoned pawn fixture | 1 | +455 cp | 24 | `d1d4` | `d1d4` |
| Starting position | 4 | 0 cp | 6,439 | `e2e4 e7e5 d1g4 d8f6` | `e2e4` |

The poisoned-pawn library result reports 23 of its 24 total nodes as quiescence nodes. Each UCI
search was submitted twice in the same release process; score, total nodes, principal variation,
and best move were identical. `isready` returned `readyok` before and after the searches.
