# M6 verification: baseline search

- Date: 2026-09-28
- Build profile for empirical runs: `release`

## Independent reference check

The test `alpha_beta_matches_unpruned_negamax_and_visits_fewer_nodes` searches the starting
position to depth 3 with both alpha-beta and a deliberately unpruned negamax reference. It requires
identical scores and strictly fewer alpha-beta nodes. The release-mode run visited 909 nodes with
alpha-beta and 9,323 nodes without pruning (a 90.3% reduction). Run it with:

```sh
cargo test --release search::tests::alpha_beta_matches_unpruned_negamax_and_visits_fewer_nodes \
  -- --nocapture
```

after the searches.
